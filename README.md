# 🍥 Shinobi Online — Launcher Windows v0.3.1

**Le launcher officiel de Shinobi Online est disponible sur Windows 10 et Windows 11 (64 bits) !**

Profitez d'une nouvelle façon de jouer à Shinobi Online, conçue pour offrir une expérience plus fluide, plus stable et plus pratique.

## 🚀 Fonctionnalités

- **Chargement optimisé** — Les fichiers du jeu sont téléchargés une seule fois, puis conservés localement pour éviter les téléchargements inutiles.
- **Vérification et réparation** — Les fichiers sont contrôlés grâce aux empreintes SHA-256 et réparés si nécessaire.
- **Mises à jour automatiques** — Le launcher détecte les nouvelles versions et vous propose leur installation après vérification.
- **Informations en direct** — Retrouvez les actualités, les notes de patch et l'état du serveur.
- **Progression conservée** — Retrouvez votre compte, vos personnages et votre progression habituelle.

## 📦 Téléchargement

**Shinobi-Online-Setup-0.3.1-x64.exe**  
Installateur Windows classique — **recommandé**.

**Shinobi-Online-Portable-0.3.1-x64.exe**  
Version portable, sans installation.

Fichiers complémentaires :
- `launcher-release.json` — Manifeste signé utilisé pour vérifier les versions.
- `SHA256SUMS.txt` — Empreintes SHA-256 des exécutables.

## 🛡️ Sécurité et Windows SmartScreen

Cette première version ne dispose pas encore d'une signature Authenticode.

Windows SmartScreen peut donc afficher un avertissement lors du premier lancement.

Si vous avez téléchargé le launcher depuis notre dépôt GitHub officiel et vérifié son empreinte SHA-256, vous pouvez sélectionner **Informations complémentaires**, puis **Exécuter quand même**, si Windows propose cette option.

Nous travaillons à améliorer progressivement la distribution et la signature de nos applications.
